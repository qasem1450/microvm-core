# محرك المحاكاة الافتراضية المصغر (microvm-core)

محرك محاكاة افتراضية خفيف وعالي الأداء (MicroVM Hypervisor) مبني من الصفر بلغة **Rust** لبيئة لينكس (`x86_64`)، مصمم لتوفير بيئات تنفيذ معزولة وآمنة وسريعة الإقلاع لتشغيل الأكواد ووكلاء الذكاء الاصطناعي.

## المميزات الحالية
* **إدارة الذاكرة (Guest Memory):** تخصيص وإدارة الذاكرة الفيزيائية للضيف بكفاءة عبر استدعاءات النظام المباشرة.
* **واجهة النواة (KVM Integration):** التفاعل المباشر مع بوابة المحاكاة في لينكس لإنشاء الأجهزة الافتراضية.
* **المعالج الافتراضي (vCPU):** تهيئة وإدارة وحدات المعالجة الافتراضية.

## المتطلبات والتشغيل
1. نظام تشغيل **Linux** بمعمارية `x86_64`.
2. توفر أداة البناء **Cargo** ومترجم **Rust**.
